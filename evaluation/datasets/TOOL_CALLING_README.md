# Tool Calling 固定开发集

`tool_calling_cases.jsonl` 的 36 条预期由 AI 辅助编写，独立人工复核状态全部为 **pending**。
全部使用仓库模拟客户、模拟订单与政策；不是实际客户记录、独立测试集或真实千问输出。

标签在运行前明确为工具集合、预期拦截原因、运行末态。不得按模型输出修改标签以提高分数。
`expected_tools` 衡量模型提议名称的集合；参数合法、权限和实际执行使用单独指标。
故意注入错误参数/越权工具的样例应导致安全拒绝或确定性回退；场景通过不代表模型选择正确。

本集覆盖只读正常请求、串行多工具、普通问候、缺订单追问、外部订单、禁止工具、身份伪造、
坏参数、重复调用ID、轮数预算、超时/429、格式错误、无证据回答、事实编造、政策注入及3A回退。
三轮记忆、原审核接口、SQLite恢复、重复审批和工单幂等另由集成测试及 `verify_tool_calling` 验证。
运行报告记录数据集SHA256、源码/政策指纹和逐题断言；运行产物放在忽略的 `evaluation/reports-*/`。
